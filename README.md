# Todo-Listinator 3000

Welcome to the Todo-listinator 3000!

It's a todo list that helps you keep track of your tasks.

## Feature list

1. Add tasks
2. Delete tasks
3. List tasks
4. Mark tasks as complete
5. Saves tasks for use in the future

## File structure

- data/
  - completed_tasks.txt # Stores completed tasks
  - tasks.txt # Stores pending tasks
  - backup.zip # Because saving overwrites old data, we've provided a backup.
- main.py # Main scripts
